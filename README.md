# Weather App - iCET Project

A modern, clean weather dashboard application built using HTML5, CSS3 (with Tailwind CSS), Vanilla JavaScript, and the [WeatherAPI.com](https://www.weatherapi.com/) service.

## Features
- Real-time weather data fetching via WeatherAPI
- 7-day forecast and hourly forecast views
- Celsius (°C) and Fahrenheit (°F) temperature toggle
- Detailed weather metrics: UV Index, Wind speed & direction, Sunrise/Sunset, Humidity, Visibility, and Air Quality (AQI)
- Location search with live suggestions and geolocation support
- Clean, responsive dashboard UI matching modern design standards

## Tech Stack
- HTML5
- CSS3 / Tailwind CSS / Phosphor Icons
- Vanilla JavaScript (ES6+ Fetch API)
